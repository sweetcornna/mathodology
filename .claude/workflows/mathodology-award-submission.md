# Modeling submission prompt

Use this as a starting brief, not a sequence of compulsory phases.

> Read the problem, data and existing work. Identify the required decisions and
> outputs, check applicable contest rules, and clarify only missing constraints
> that would change the answer. State defensible assumptions and keep working.
>
> Establish a useful baseline, then add model complexity only when it improves
> the answer. Define units, objectives, constraints and what the data can identify.
> Challenge the headline result with an appropriate baseline, diagnostic and
> sensitivity or adverse scenario. Keep calculations traceable to actual inputs.
>
> Use mathodology-evidence-search for external claims and licensed references.
> Select purposeful figures with mathodology-figure-presets. At the first figure
> design, ask once about image2 availability and its access method, unless the
> task already has an answer. Continue independent work while waiting. Use image2
> for supported illustrations or layout concepts; derive quantitative marks from
> data. Default to the figure skill's callable code templates when image2 is
> absent or pending: supply real arrays, execute the code and export PNG/PDF.
> Do not stop at prompts alone. Do not mislabel a different image model as image2.
>
> Explain the result in the problem's terms. Use mathodology-award-gates to review
> consequential mathematical, empirical and presentation issues. Inspect actual
> figure exports and dense pages of the final paper. Deliver the requested files,
> reproduction instructions, verified citations and material limitations.

The main agent can use the focused roles in `.claude/agents/` when useful and
supported by the host. Brief each role with the question, relevant evidence,
constraints and expected output. Share the image2 answer and agree file ownership.
Ordinary prose and working artifacts are sufficient; no phase gates, fixed judge
panels, scores or handoff schemas are required.

For task-specific emphasis, see [contest variants](mathodology-contest-variants.md).
