# Contest-specific emphasis

Read the current official problem and rules before adopting contest-specific
requirements. Do not carry page limits, dates or AI policies from a past event.
Official rules and the user's deliverable constraints take precedence.

| Task type | Adapt the modeling work |
|---|---|
| MCM/ICM, CUMCM, Huashu and similar papers | Connect each question to a supported conclusion; prioritize mathematical validity, meaningful comparisons, clear figures and an economical summary. |
| M3 or other short sprint | Establish a feasible baseline early, focus experiments on decisions that could change the answer, and protect time for a readable final document. |
| HiMCM/MidMCM, IMMC/IM2C | Match mathematical depth to the problem and audience; explain assumptions and computations so the reasoning can be followed. |
| Leaderboard/data science | Respect data split, leakage, submission schema and evaluation rules; separate tuning from validation and quantify variability when supported. |
| Operations, policy or business case | Expose feasibility, costs, affected groups, tradeoffs and adverse scenarios; make recommendations conditional where uncertainty matters. |
| Unlisted contest | Infer the closest emphasis from the actual prompt and outputs, then explain any additional requirements without importing an unrelated workflow. |

All variants use the same evidence and figure skills. Figures serve the argument;
there is no fixed quota. image2 availability is asked once when figure design
begins, and unavailable imagery does not block numerical modeling. AI-use
reporting follows the actual event's rules. Neither internal review nor visual
polish justifies a guaranteed prize prediction.

Use [the submission prompt](mathodology-award-submission.md) as an adaptable brief.
