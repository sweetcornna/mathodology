# image2：主动询问与实际使用

本文件是交互提示词，不是接入服务或模型路由代码。image2 是用户指定的
模型名称；以用户已配置入口和工具实际能力为准，不猜测其厂商、版本或参数。

## 在当前任务中只询问一次

首次设计图表时，先查看本任务对话中是否已有 image2 的回答。如果没有，使用
宿主提供的提问机制询问：“是否有可用的 image2 模型？通过当前工具、已配置
接口，还是手动生成使用？”专业角色沿用主对话已知状态，不各自重新询问。
普通进度更新不夹带问题。用户迟迟不答时继续数据分析和常规绘图，不反复追问。
用户后续改变选择时更新当前任务的做法；新建模任务再询问一次。

## 没有 image2 时默认实际出图

使用 [20 类绘图代码模板](../templates/README.md)，将本题真实数据填入匹配函数，
实际运行并导出 PNG/PDF。尚未回答或仅能手动使用 image2 时也按此路径继续。
不只交付绘图提示词，不等待图像模型。模板不适配时修改最接近的代码，不能
拿合成样张当本题结果。有 image2 时，真实数值图仍默认由代码模板绘制。

## 根据真实入口工作

| 已知情况 | agent 的做法 |
|---|---|
| 有可调用 image2 工具或已配置接口 | 核验工具是否确实支持该模型、用户要求的图像任务及必要输入；按实际工具 schema 调用。报告真实调用结果，不虚构模型参数或成功记录。 |
| 用户手动使用 image2 | 给出可复制提示词、画幅、配色、准确文字和参考图说明；可继续生成数据图，待用户返回素材后检查与整合。 |
| 没有 image2 | 使用已有数值绘图库或适用的其他绘图工具。若使用另一图像模型，如实说出已知工具名称，不冒称 image2。 |
| 未回答或回答“稍后再说” | 完成分析、图表选型和常规绘图；保留可选的配图提示词，待用户回应后衔接，不把等待变成全任务阻塞。 |
| 声称有接口但当前无法调用 | 说明当前无法直接调用；交付手动提示词并继续独立工作。不要新建服务适配框架或要求聊天中提供密钥。 |

## 配图与数值分工

- 适合 image2：场景配图、机制示意图、研究对象结构、流程布局和论文图形摘要。
  这些图也必须符合已确认的机制，不添加不存在的设备、因果箭头或模型组件。
- 含真实数值的图：坐标、曲线、点、面积、误差区间、色条和数值标签应由数据
  或公式计算生成。image2 可以提出布局或非定量插画层，最终数值层由绘图库重绘。
- 不根据生成图片反推“实验数据”。不能仅凭看起来相似就接受 image2 重绘的
  数值图；检查文字、符号、箭头与公式。生成式示意图在图注中标明性质，并按
  本次比赛的实际要求记录 AI 使用。已有图片编辑遵循宿主的图像编辑工具规则。

## 可直接复制：机制示意图

> 为数学建模论文绘制机制示意图，画幅为 {尺寸}，白色背景，阅读方向为 {方向}。
> 只包含已确认的对象 {对象清单}，关系 {有向边及含义}，边界条件 {边界}。
> 使用蓝、橙与灰区分 {对应语义}，颜色之外用形状或线型提供冗余编码。
> 不添加未提供的因果关系、设备、公式或数值。短标签严格使用 {准确文字}；
> 若无法可靠生成文字，请留出清晰的标签位置，由后续矢量排版添加。
> 保持线条简洁，避免立体光影和装饰背景，给图注与子图编号留空间。
> 本图用于说明模型结构，不代表实测图像或定量结果。

## 可直接复制：图表版式探索

> 为论文中的 {研究问题} 设计 {画幅} 图表版式。主面板回答 {核心比较}，
> 辅面板分别回答 {诊断或不确定性}，优先使用 {预设编号} 的结构。
> 仅规划面板尺寸、标签位置、图例、色条和配色。数值区域使用占位符，
> 不生成真实实验数值、曲线或显著性符号。最终图表将从源数据重新绘制。
> 单栏缩放后仍应可读；不要用图案、渐变背景或多余面板增加复杂度。

## 提示词演练场景

维护这些提示词时，检查四个主要情形：可调用、手动、不可用、未回答。
同时检查同一任务已有回答、专业角色接手、工具名称不明及调用失败的情况。
预期行为是正确沿用状态、继续独立工作并真实报告能力。演练是人工推演，
不能宣称已实测不存在的 image2 接口，也不能保证未来每次模型行为一致。
