# 论文图表的统一设计建议

以下数值是起点，根据期刊/比赛要求、字体和最终尺寸调整，不作为自动验收阈值。

## 版面与文字

- 从最终纸面宽度设计：单栏约 85 mm、跨栏约 175 mm，可随正文版心调整。
  为图注留空间。复杂图通常用跨栏；拥挤时拆图，不把文字无限缩小。
- 以实际纸面约 8–10 pt 的刻度文字、9–11 pt 的轴标签试排；密集图需要更大
  画幅或更少元素。文字与正文协调，中文使用已安装且覆盖所需字符的字体。
  检查缺字警告，不用占位方框代替文字。
- 主线约 1.4–2 pt，辅助线约 0.7–1 pt。子图用 (a)、(b) 等稳定编号，位置
  一致且不遮盖数据。正文图注已有完整标题时，图内只放简短面板标题。
- 保留有意义的留白供图例、色条或解释；优先共享轴、对齐刻度和直接标签。
  调整布局结构来处理遮挡。允许有明确意义的标注覆盖，不做几何碰撞硬判定。

## 颜色与视觉编码

- 分类色起点：蓝 #0072B2、橙 #D55E00、绿 #009E73、紫 #CC79A7；基线灰
  #7A7A7A。统一同一情景在全文的颜色，辅以线型/点形，检查灰度可分辨性。
- 有序强度使用顺序色图（如 viridis/cividis）；正负差异使用以有意义的零点
  为中心的发散色图；分类不用连续色条。不要把所有数据都套彩虹色。
- 分面之间若比较绝对大小，应共享色条范围与单位。缺失、不适用与零值使用
  不同编码。透明度只为减轻遮挡，不作为未经说明的第三个数值维度。
- 面积编码应让面积与值成比例，不能让半径与值成比例。显示大小图例。
  条形比较通常从零起；截断、对数、标准化或断轴必须明确说明。

## 统计含义

说清观测单位、样本量、汇总方式、重复测量、估计方法和区间定义。
95% 置信区间、95% 预测区间与 95% 模拟分位范围不能互换。置信带是否
同时覆盖整条曲线要单独说明。误差条重叠不是正式的显著性检验。
先确定模型/比较规则，再看结果；不要删掉不利点或选择最好的一次随机运行。
不确定性不存在时不要编造区间。只有汇总量时不要伪造原始散点或分布。

## 导出和检查

以 PDF/SVG 等矢量格式保存线条与文字；密集散点可栅格化数据层，保留文字
矢量。另导出约 300 dpi PNG 便于预览，若比赛另有要求则遵从。保存绘图
脚本/可运行单元、生成命令、实际依赖版本和随机种子（涉及随机数时）。

先核对图与源数据、单位、统计定义，再在最终插入尺寸下检查字体、线条、
子图编号、色条与图例。检查论文中的实际页面，特别是跨页图注、裁切和缩放。
可用宿主 PDF 渲染工具或可选的页面总览工具，但总览不能替代密集区域细看。

图注应说明：回答什么问题、各面板怎样读、样本/情景与方法、区间含义、
实际观察到的结论及限制。数值从结果中填入，不照抄示例的虚构结论。
