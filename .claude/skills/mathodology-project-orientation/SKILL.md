# Mathodology Repository Orientation

The repository boundary (what is maintained where, what must not be added, the
`.agents/skills/` mirror, `.mcp.json`, where contest output lives) is defined in
the root [AGENTS.md](../../../AGENTS.md); apply it as written.

A reference figure is teaching material, not contest evidence; keep synthetic
previews visibly labeled and reproducible. For maintenance, optionally run the
repository checker described in
[maintenance](../mathodology-dev-test-release/SKILL.md); it verifies metadata,
references and boundaries, not mathematical quality.
